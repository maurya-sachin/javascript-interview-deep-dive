# JavaScript Interview Deep Dive

JavaScript from the language down to the spec and the engine, then up through its runtimes — written as interview questions.
Not an introduction: work through a topic and you should be able to explain *why* it behaves the way it does.

> **Status:** v2 is being rebuilt from scratch. The previous version is still live at
> [maurya-sachin.github.io/javascript-interview-deep-dive](https://maurya-sachin.github.io/javascript-interview-deep-dive/).

## What each question gives you

1. **Quick answer** — what you'd say in the first 30 seconds of an interview.
2. **Answer** — the full answer, one example, the pitfalls interviewers probe, likely follow-ups.
3. **Deep dive** — how it works at the spec/engine level, edge cases, a real-world scenario, trade-offs.
4. **Exercises** — predict-the-output and fix-the-bug puzzles.

Questions are ordered, so a topic reads like a book. A web app adds practice mode, flashcards, and search.

## Roadmap

The JavaScript language first, completely. Then TypeScript, the browser and Node.js runtimes, and the frontend and backend tracks built on them.
