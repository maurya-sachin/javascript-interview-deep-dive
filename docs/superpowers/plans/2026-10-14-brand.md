# Brand (isobath identity) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the app its isobath identity: name, contour mark and favicon, a header lockup, generated contour-map covers per topic, depth-scale colour tokens, and the CC BY-NC-SA licence notice.

**Architecture:** One pure module (`src/lib/contours.ts`) turns a seed into nested closed rings (value field → marching squares → chained rings). A `TopicCover` component draws them; a `Mark` component and a static favicon carry the logo. Colours reuse the existing depth ramp, split into four named stops. No new dependencies.

**Tech Stack:** TypeScript, React 19, Tailwind 4, `node:test` for the pure module.

**Spec:** `docs/superpowers/specs/2026-10-14-isobath-redesign-design.md` → §2 Brand. Layout reference: `docs/superpowers/specs/mockups/page-layouts.html`.

## Global Constraints
- Name shown as "isobath, by Sachin Maurya"; tagline "engineering interviews, in depth".
- Fonts Geist, Geist Mono, Newsreader (SIL OFL); accent `#2F4FD8` light / `#9DAEF7` dark; prose column 720px.
- Mark = nested irregular contours; the drawn mark is a **draft** a human designer will redraw. Originals only: nothing copied from other brands.
- Covers are original by construction: generated from the topic slug and data, no hand drawing, no AI image.
- Existing look must not regress: `--depth-from` / `--depth-to` keep their values.
- Never bulk-read `content/`, `app/public/data/`, `app/dist/`.
- R9: Node 24 native TypeScript (`erasableSyntaxOnly`, `.ts` import extensions in scripts/tests).
- Branch `v2`; one concern per commit.

## Review Focus
- Every cover must be valid for any slug and any chapter count, including a planned topic with 0 chapters and a topic with 30: closed rings, inside the frame, never empty.
- Dark mode: the mark, favicon and covers stay visible against the dark background.
- The cover must not change between renders or page loads (same slug, same art).
- A topic with only one or two chapters still gets a recognisable map (minimum 3 levels).
- Page titles and the browser tab say isobath everywhere; no "Deep Dive" left in app strings.
