What is the difference between ECMAScript, the engine, and the host?
Read the questionBrowse JavaScript
30-second answerECMAScript is the language specification. The engine, such as V8, implements it. The host, such as a browser or Node.js, adds APIs like setTimeout and fetch that the spec does not define.

ECMAScript, the engine, and the host

30-second answerECMAScript is the specification. An engine such as V8 implements it. The host adds APIs the spec never defines.
Chapters1 of 12 · open

When someone says "JavaScript does X", the claim usually belongs to one of three layers. Naming the layer is most of the answer.

The specification defines syntax, types, and the abstract operations an implementation must follow. It says nothing about timers or the network.
