# Accessibility

> **Status:** 🔴 planned · **Published:** 0/0 · **Last verified:** —

Building interfaces everyone can use: semantics, the accessibility tree, ARIA, keyboard and focus, and WCAG.
Senior frontend interviews expect it, and it's the area where "it works for me" answers fail most visibly.

## Scope

- **In:** WCAG principles and conformance, the accessibility tree and accessible names, ARIA roles/states/properties, keyboard and focus management, accessible widget patterns, live regions, visual accessibility, testing with tools and assistive technology.
- **Out:** HTML element semantics in general → [HTML and CSS](../html-and-css/) · framework-specific focus handling → [React](../react/).
