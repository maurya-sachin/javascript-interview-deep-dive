# HTML and CSS

> **Track:** Frontend
> **Status:** 🔴 planned · **Published:** 0/41 · **Last verified:** —

Markup and styling as the platform defines them: semantic HTML, forms, the cascade, and layout.
Interviews use them to separate engineers who understand layout from those who adjust values until it looks right.

## Scope

- **In:** semantic HTML, forms and validation, document metadata; the cascade, specificity, and layers; the box model and formatting contexts; flexbox, grid, positioning, and stacking contexts; responsive design; modern CSS features.
- **Out:** how the browser renders it, script loading, and Web Components → [Browser runtime](../browser/) · labels, ARIA, and assistive technology → [Accessibility](../accessibility/) · CSS loading, responsive images, and font loading → [Web performance](../web-performance/).

## Prerequisites

None — this track stands on its own.
