# Data structures and algorithms

> **Track:** Engineering practice
> **Status:** 🔴 planned · **Published:** 0/0 · **Last verified:** —

The data structures and algorithm patterns behind coding rounds, implemented and analysed in JavaScript.
Coding interviews grade the reasoning — complexity, trade-offs, edge cases — as much as a working solution.

## Scope

- **In:** complexity analysis, arrays and strings, hash maps and sets, linked lists, stacks and queues, trees and BSTs, heaps, graphs, tries, sorting and searching, recursion and backtracking, dynamic programming, greedy algorithms, common problem patterns (two pointers, sliding window, BFS/DFS).
- **Out:** how JavaScript's built-ins behave (`Array.prototype.sort`, `Map` ordering) → [JavaScript](../javascript/) · designing whole systems → [System design](../system-design/).

## Prerequisites

[JavaScript](../javascript/) — especially arrays, `Map`/`Set`, and recursion.
